# Syed Ahmed Shah Gillani — Portfolio

Personal portfolio built with React, TypeScript, Vite, and Tailwind CSS v4.

## Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- lucide-react

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deployed on Vercel. Push to `main` and import the repo at https://vercel.com/new.
